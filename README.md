## 项目介绍

本项目 fork 自 [legadoC](https://github.com/CCSSNE/legadoC)，在此基础上针对阅读、听书体验做了针对性优化：

- 阅读进度同步增强（WebDAV 批量拉取修复、纯位置比较、DEBUG 版自动同步）
- 朗读悬浮窗优化（阅读界面内隐藏悬浮窗，离开后显示）
- 新增 sk2 共存测试版（`io.legado.app.sk2`，应用名「阅读SK」）

感谢 [legadoC](https://github.com/CCSSNE/legadoC) 原作者的无私奉献！
